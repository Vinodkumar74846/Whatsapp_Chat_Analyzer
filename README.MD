# 📱 WhatsApp Chat Analyzer

✨ **WhatsApp Chat Analyzer** is a Python-based web application that analyzes exported WhatsApp chats and generates useful insights such as message statistics, timelines, word usage, emoji patterns, and sentiment analysis.

The project uses **Streamlit** to create an interactive dashboard where users can upload their chat files and explore different types of analysis.

---

# 🎯 Project Objective

The goal of this project is to analyze WhatsApp chat data and extract meaningful insights about conversations, user activity, and communication patterns using **data analysis and visualization techniques**.

├── README.md

### File Description

**app.py**  
Main Streamlit application file that runs the dashboard.

**preprocessor.py**  
Processes the raw WhatsApp chat text file and converts it into a structured dataframe.

**helper.py**  
Contains functions used for analysis such as statistics, timelines, word cloud generation, and emoji analysis.

**requirements.txt**  
List of all Python libraries required to run the project.

# ⚙️ Installation Guide

Follow the steps below to run the project on your system.

## 1️⃣ Clone the Repository

```
git clone https://github.com/yourusername/whatsapp-chat-analyzer.git
```

---

## 2️⃣ Navigate to Project Folder

```
cd whatsapp-chat-analyzer
```

---

## 3️⃣ Install Required Libraries

```
pip install -r requirements.txt
```

---

## 4️⃣ Run the Application

```
streamlit run app.py
```

After running the command, the application will open automatically in your browser.

# 📥 How to Export WhatsApp Chat

Follow these steps to export a WhatsApp chat file.

1️⃣ Open **WhatsApp**

2️⃣ Open the **chat conversation**

3️⃣ Click **Menu (⋮)**

4️⃣ Select **More → Export Chat**

5️⃣ Choose **Without Media**

6️⃣ Upload the exported **.txt file** into the application.
